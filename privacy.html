Privacy Policy

Last updated: October 22, 2026

YouTube Dabao Uploader uses YouTube API Services.

By using Dabao Uploader you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Who uses this tool

Dabao Uploader is an internal tool. The only accounts that sign in are the owners of our own YouTube channels. It is not offered to the public.

What data we access

When a channel owner signs in with Google (OAuth 2.0), the tool receives an access token for the scopes youtube.upload and youtube.force-ssl. It uses them only to read the signed-in channel's ID and name, upload videos, set thumbnails, upload captions, add videos to playlists and update the status of videos on that same channel.

What data we store, and where

The OAuth tokens are stored only on our own work computer, in a local folder that is not shared or synced. After each upload, the tool writes the resulting video ID, URL and privacy status into a local project file so we know what was published. We do not store any other YouTube API data, we do not collect data about viewers or other users, and we do not share any data with third parties. We do not use cookies or any tracking.

How to revoke access and delete data

A channel owner can revoke the tool's access at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or on request by email, we delete the stored tokens within 7 days. Locally recorded video IDs are deleted together with the project files, and in any case within 30 days of a request.
